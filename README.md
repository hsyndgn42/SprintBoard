# SprintBoard

SprintBoard, sprint planlama ve takibi için geliştirilen bir ürün denemesidir.

Bu dosya, GitHub deposunda ilk commit'i oluşturmak ve talep → taslak Pull Request akışını güvenli bir örnekle denemek için eklendi. Pilot akış, `requests/` klasörüne gerçek sprint verisi içermeyen örnek bir JSON talebi gönderecektir.

## Mevcut durum

- Uygulama verileri şu anda tarayıcının yerel depolama alanında tutulur; GitHub deposuyla otomatik eşitlenmez.
- GitHub bağlantısı, uygulamadaki **Ayarlar → GitHub PR pilotu** bölümünden Admin tarafından yapılandırılır.
- Erişim anahtarı bu depoya, README dosyasına veya uygulama yedeğine eklenmemelidir.
- Mevcut demo giriş bilgileri temizlenmeden uygulama kaynakları bu depoya yüklenmemelidir.

Bu aşama yalnızca entegrasyon denemesidir; kurumsal kimlik doğrulama veya ortak veri deposu değildir.
